## Agen Meta Ads — Facebook, Instagram, Threads (Claude Code)

Tiga subagent dalam `.claude/agents/`:

| Agen | Kepakaran |
|---|---|
| `fbscale` | Strategi, scaling & profit (unit economics, struktur campaign, bajet) |
| `fbcontent` | Ad copy, hook, skrip video/UGC, angle creative (FB, IG, Threads) |
| `fbdoktor` | Diagnos masalah ads & improve prestasi |

Cara guna: minta terus dalam Claude Code, contoh *"fbdoktor, kenapa CPA aku naik minggu ni?"*
