## Agen Facebook Ads (Claude Code)

Tiga subagent dalam `.claude/agents/`:

| Agen | Kepakaran |
|---|---|
| `fb-ads-strategist` | Strategi, scaling & profit (unit economics, struktur campaign, bajet) |
| `fb-content-copywriter` | Ad copy, hook, skrip video/UGC, angle creative |
| `fb-ads-doctor` | Diagnos masalah ads & improve prestasi |

Cara guna: minta terus dalam Claude Code, contoh *"guna fb-ads-doctor, kenapa CPA aku naik minggu ni?"*
