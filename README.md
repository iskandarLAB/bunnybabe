## Agen Facebook Ads (Claude Code)

Tiga subagent dalam `.claude/agents/`:

| Agen | Kepakaran |
|---|---|
| `scale` | Strategi, scaling & profit (unit economics, struktur campaign, bajet) |
| `copy` | Ad copy, hook, skrip video/UGC, angle creative |
| `doktor` | Diagnos masalah ads & improve prestasi |

Cara guna: minta terus dalam Claude Code, contoh *"doktor, kenapa CPA aku naik minggu ni?"*
